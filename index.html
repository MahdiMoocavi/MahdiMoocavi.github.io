PYTHON DATA PROCESSING

Excel preprocessing, feature construction, and audit trails

This Python pipeline transforms study-specific Excel exports into analysis-ready workbooks. It handles participant filtering, variable harmonisation, derived measures, and open-text preprocessing, while preserving an audit trail so suggested text corrections can be reviewed rather than silently accepted.

The workflow is designed for a defined replication-data schema rather than as a general-purpose ingestion tool. Its filtering thresholds, recoding rules, and scoring transformations are documented so the assumptions behind each processed dataset remain inspectable.
